# Art direction and credits

Victorian elegance: ivory paper, bottle-green ink, antique brass, serif headings and restrained bookplate ornament. Native Android interactions keep controls readable and usable.

`app/src/main/res/drawable-nodpi/library_engraving.png` was generated for this project using OpenAI image generation on 2026-11-02. The brief called for a Victorian library nook in copperplate/wood-engraving style: an open book, reading chair, arched shelves and botanical details. No external cover or artist’s work was supplied as a reference. The original generated illustration is retained as a project asset.

Bookplate placeholders are drawn by the app using initials and ornament, not official cover art. Screenshots contain demonstration data supplied by UI verification.
